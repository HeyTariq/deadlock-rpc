Deadlock not showing on Discord?

Work through these checks to get "Playing Deadlock" back in your Discord status, then add your hero and match details with rich presence.

If Discord doesn't show Deadlock at all

1. Turn on activity sharing

In the Discord desktop app, open User Settings, then Activity Privacy, and turn on the option to share your detected activities with others. If it's off, nobody sees what you're playing, including rich presence.

2. Check your status isn't Invisible

Discord hides your activity while your status is set to Invisible. Switch to Online, Idle, or Do Not Disturb.

3. Use the desktop app, not the browser

Discord in a web browser can't see which games are running on your PC, and apps can't send it rich presence. Install and run the Discord desktop app.

4. Add Deadlock as a registered game

With Deadlock running, open User Settings, then Registered Games. If Deadlock isn't listed as the current game, click Add it! and pick Deadlock from the list. Discord remembers it from then on.

5. Check your settings for individual servers

Discord also lets you hide your activity in specific servers. Right-click the server icon, open Privacy Settings, and make sure activity status is on for that server.

6. Don't run Discord or the game as administrator

On Windows, if one of Discord or Deadlock runs as administrator and the other doesn't, Discord can fail to detect the game. Run both normally.

Does Deadlock have Discord rich presence?

Not built in. Even when everything above is set up, Discord only shows "Playing Deadlock" and how long you've been playing. The game doesn't tell Discord which hero you're on, what mode you're in, or whether you're in a match.

Deadlock Rich Presence is a free, open-source app that adds those details. It reads the game's console log and updates your Discord profile with your hero portrait, game mode, and match state as you play. It never touches game memory or files, so it's VAC safe. You can try the interactive demo to see what it looks like.

If Deadlock Rich Presence is running but not working

My status shows nothing from Deadlock RPC

Make sure the Discord desktop app is open before you start Deadlock RPC, and that activity sharing is on (step 1 above). Then restart Deadlock RPC.

My hero, mode, or match state isn't updating

The game was most likely started without the -condebug launch option, so it isn't writing the log the app reads. Launch Deadlock through Deadlock RPC, which adds it for you, or add it to Deadlock's launch options in Steam yourself. What -condebug is and how to add it.

Deadlock RPC can't find the game

The app finds Deadlock through your Steam library folders. If it can't, set game_folder in config.toml to your Deadlock install folder (the one that contains game). In Steam, right-click Deadlock and choose Manage, then Browse local files to find it.

Still stuck?

Check the logs/ folder next to the app for errors, then open a GitHub issue with the log attached.
