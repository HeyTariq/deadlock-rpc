What is -condebug in Deadlock?

A built-in Valve launch option that saves the game's console output to a file. Here's what it does, where the file goes, and how to turn it on.

What does -condebug do?

Deadlock has a developer console that prints a running log of what the game is doing: loading maps, joining matches, picking heroes, connecting to servers. Normally that text only lives in memory. Starting the game with -condebug tells it to also write every line to a file called console.log.

It's the same option that works in other Valve games like Counter-Strike and Dota 2. Deadlock just puts the file in its own folder.

Is -condebug safe? Can it get me VAC banned?

Yes, it's safe. -condebug is a launch option the game supports out of the box. It doesn't change gameplay, inject anything, or modify game files. It only tells the game to save text it was already printing. VAC looks for cheats that tamper with the game, and a launch option Valve built in isn't one of them.

Does it affect performance?

Not in any way you'll notice. Writing a few lines of plain text to one file is a tiny amount of work next to rendering the game.

How do I add -condebug to Deadlock?

  1. Open Steam and go to your Library.
  2. Right-click Deadlock and choose Properties.
  3. On the General tab, type -condebug in the Launch Options box. If something is already there, add it after a space.
  4. Close the window and launch Deadlock as usual.

To turn it off again, delete -condebug from the same box.

Where is Deadlock's console.log?

It's in the game/citadel folder inside your Deadlock install. With a default Steam library:

Windows:

C:\Program Files (x86)\Steam\steamapps\common\Deadlock\game\citadel\console.log

Linux:

~/.local/share/Steam/steamapps/common/Deadlock/game/citadel/console.log

If you installed Deadlock in a different Steam library, right-click Deadlock in Steam and choose Manage, then Browse local files to open the install folder. The file only appears after you've launched the game with -condebug at least once.

Why would I want it?

Mostly for tools that read the log to see what's happening in your game, and for digging into crashes or connection problems. Deadlock Rich Presence uses it to show your hero, game mode, and match state on your Discord profile. The game tells nobody else what you're doing, so the log is the only safe place to read it from.

Do I need to add it for Deadlock Rich Presence?

Usually not. When Deadlock Rich Presence starts the game for you, it adds -condebug on its own. You only need to add it yourself if you launch Deadlock straight from Steam and start the app separately. The setup guide covers all three ways to launch the game.
